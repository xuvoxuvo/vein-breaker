# 设计简报：Vein Breaker（射击方向）

> 状态：v0.4（2026-10-26）
> **方向调整**：放弃「弹球打砖块」的保球玩法，改为传统第一人称射击采矿。
> 具体规则见 [玩法规格](./gameplay-spec.md)，实现状态见 [原型说明](./prototype-01.md)。

## 0. 转向记录

原方案 A（人身挡板弹球）已完成设计与验证计划，但未进入实现。现改为：
**用枪射击矿层 → 矿砖破碎 → 矿石掉落 → 自动回收**。

保留的要素：矿洞空间、矿砖网格、矿石资源、第一人称走位。
去掉的要素：钻核、挡球、竖井失败线、轨迹预测。

原因：用户判断「传统射击」更接近想要的手感，先做原型再谈深度。

## 1. 一句话

你在一座坍塌的矿脉里，用一把电磁凿岩枪把矿层打成碎块，回收矿石。

## 2. 已经能玩的部分（Prototype 0.1）

| 能力 | 状态 |
|---|---|
| 第一人称移动 / 视角 / 跳跃 | ✅ |
| 命中扫描射击（hitscan）+ 后坐 + 曳光 | ✅ |
| 三种矿砖：岩石 / 铜 / 铁（HP 与价值不同） | ✅ |
| 矿石掉落、磁吸、自动计数 | ✅ |
| HUD：矿石数 / 剩余矿砖 | ✅ |
| `R` 重建矿层、`Esc` 退出、`F1` 释放鼠标 | ✅ |
| 截图模式（`--screenshot <path>`） | ✅ |
| 音效、敌人、失败条件、关卡数据化 | ❌ |

一局大约 2–4 分钟：30 块矿砖，2–3 枪一块。

## 3. 当前循环

```
进洞 → 看矿层（哪块是铁、哪块值钱）
     → 瞄准、射击、打碎
     → 磁吸回收矿石
     → 清空整层 →（未来）结算/下一层
```

目前它更像「射击靶场」而不是完整游戏——**没有压力，就没有决策**。

## 4. 最大的设计缺口：缺一个「什么时候收手」的问题

现在没有失败条件、没有资源约束、没有敌人。要让它成为游戏，需要一个压力源。三个候选：

| 方案 | 玩家在权衡什么 | 实现成本 | 风险 |
|---|---|---|---|
| **A 氧气 / 时间** | 多打一块矿 vs 留够氧气撤离 | 低 | 容易变成单纯的倒计时 |
| **B 塌方** | 打承重柱会落石封路；顶板打太多会塌 | 中 | 规则不直观，需要清晰的视觉提示 |
| **C 敌人** | 打矿 vs 打怪，弹药/仇恨管理 | 高 | 会改变游戏重心，容易变成普通 FPS |

**建议先做 A + B**：它们不改变射击手感，只增加「贪心 vs 安全」的决策，且都能用现有矿砖网格表达。
敌人留到射击手感稳定之后。

## 5. 武器与矿石的层次

- 基础伤害 1，射速约 9 发/秒，无弹药限制（原型阶段）；
- 铜矿 2 HP、铁矿 3 HP → **更值钱的矿更硬**，玩家自然会优先打软矿还是冒险打硬矿；
- 后续改装方向：蓄力重击（破硬矿）、穿透（打一排）、爆破（范围伤害，但会触发塌方）。

## 6. 下一步优先级

1. **氧气 + 撤离点**：给一局一个明确的开始与结束；
2. **关卡 RON 化**：现在矿层写死在代码里，改一次要重编译；
3. **命中反馈**：音效、碎屑、屏幕轻震——射击手感的一半在反馈；
4. **5 关曲线**：每关只加一个新变量；
5. **数值与手感调参**：射速、后坐、FOV、移动加速度。

## 7. 目标体验

- 30 秒内打碎第一块矿；
- 2 分钟内自己发现「铁更硬、更值钱」；
- 一局结束时有一个明确的「我该早点撤」或「我还想再打一层」的念头。
